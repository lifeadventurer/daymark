# Daymark

Daymark is a daily calendar puzzle where you arrange pieces to complete the
board while leaving one date open.

## Keyboard shortcuts

Select a piece, then use these shortcuts to change its orientation:

- `R`: rotate clockwise
- `Shift+R`: rotate counterclockwise
- `H`: flip horizontally
- `V`: flip vertically

The shortcuts also work while dragging a piece. A placed piece only changes
orientation when the transformed position remains legal; invalid transforms are
left unchanged.
